# Code Orbit Internship Projects

This repository contains the tasks completed as part of my **Code Orbit Internship**. The projects focus on data cleaning, sales data analysis, and interactive dashboard development using Python.

## 📌 Project Overview

### Task 1: Data Cleaning using Python
- Cleaned and preprocessed raw sales data using Pandas.
- Handled missing values and duplicate records.
- Standardized data formats and corrected date values.
- Generated a cleaned dataset and cleaning report.

### Task 2: Sales Data Analysis
- Analyzed sales data using Pandas.
- Calculated total revenue, average order value, and units sold.
- Identified top-performing products and categories.
- Analyzed sales by region and month.
- Generated analysis reports and CSV files.

### Task 3: Sales Dashboard
- Developed an interactive sales dashboard using Streamlit.
- Visualized sales performance using Plotly charts.
- Added filters for exploring sales data.
- Displayed key performance indicators and sales trends.
- Included a downloadable filtered dataset.
